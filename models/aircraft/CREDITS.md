## Screening

Each model was checked for signs of being extracted from a video game before it was added:
- game names in the listing
- game-engine texture naming (`_c`/`_n_n`/`_n_s` sets, hashed `.dds` names)
- GPU frame-capture data or game asset paths inside the file
- whether the uploader is the original author

Models that failed this check, or whose origin could not be confirmed, are not in the repository.
